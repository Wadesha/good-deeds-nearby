# 好事近 · 泛公益参与调研全案

> **把泛公益拆成 15 分钟、顺路、就近的轻量任务，用非金钱的"好心值 + 时间币"替代工资，让忙人也能把好事做成日常。**

---

## 项目简介

一个被现有志愿服务体系系统性忽略的细分人群——**"时间贫困 × 意愿充足 × 非金钱驱动 × 强地域性"**。志愿汇解决的是"组织如何管理志愿者"，腾讯公益解决的是"如何筹钱"，而"一个忙人如何在通勤和碎片时间里，顺手把好事做了"这件事，目前没有专属产品。

本项目包含完整的：

- **市场调研与需求验证**——大盘数据、人群画像、竞品分析
- **调研产品规划**——5 个核心假设 (H1–H5)、混合方法论、问卷/访谈提纲
- **产品 MVP 规划**——价值主张"好事近"、核心功能、非盈利正循环设计
- **叠加递进路径**——Phase 0 验证 → Phase 4 生态，每一层像搭乐高一样叠

### v2.0 日常微好事生态（基于日常好事库）

v2.0 将基于 [日常好事库](pages/cases.html) 中的63个日常微好事模板，落地以下功能：

1. **议事会模式**（邻里投票决定下一件共同好事）— 投票结果生成需求清单
2. **友好商户体系**（好心值兑换商户优惠）— 激励日常善行
3. **技能认证标签**（搭档匹配增加技能资质）— 义修/义剪等技能互助
4. **公益众筹**（好心值众筹+捐步换物）— 集体完成一件好事
5. **适老改造场景**（场景匹配器新增上门服务）— 药箱整理/居家改造
6. **时间银行**（时间币存储制+三单联动）— 让日常好事可存储、可追溯

### 日常好事库说明

日常好事库中的63个模板均为日常小型社区微好事，覆盖6大类别：
- 邻里互助（9个）— 帮取快递、共享雨伞、帮提菜等
- 随手环保（8个）— 垃圾分类、摆正单车、清理小广告等
- 技能顺手（9个）— 教老人用手机、帮打印、修家电等

- 节日小事（9个）— 包饺子分邻居、写春联、端午挂艾草等
- 闲置共享（10个）— 图书漂流、旧衣回收、共享工具箱等

## Phase 0 行为探针验证方案

> **方案来源**：基于[经营分析报告](好事近-经营分析报告.md)中"建议 1：完成行为探针验证"展开。行为探针是 Phase 0 验证中成本最低、信号最真的验证手段，直接决定"时间贫困者想做好事"这一核心假设的真伪。

### 1. 验证目标

| 验证对象 | 假设 | 当前状态 |
|---|---|---|
| H3 | 非金钱激励（好心值/信用/社区荣誉）足以驱动持续参与 | 🔄 验证中 |
| H5 | 地域性（社区/LBS）是匹配关键 | 🔄 验证中 |
| 整体 | 时间贫困者在真实场景中会主动参与"就近轻量好事" | 🔄 待验证 |

### 2. 探针设计原则

```
问卷说"我愿意"   →   低成本、高噪音     ← 已做完（N=612）
访谈说"我会做"   →   有深度、样本小     ← 已做完（N=30）
行为探针"真做了" →   最高信号、最真实   ← 现在做（N=50）
```

**核心原则**：不依赖被试者"说"什么，只看"做"了什么。行为数据比态度数据至少高一个置信度等级。

### 3. 参与者招募

#### 3.1 招募条件

| 条件 | 要求 | 原因 |
|---|---|---|
| 年龄 | 25-40 岁（占目标人群 68.3%） | 与问卷画像一致 |
| 城市 | 一线或新一线（占样本 70%） | 有"15 分钟生活圈"基础 |
| 通勤 | 每日通勤时间 ≥ 30 分钟 | 保证碎片时间场景存在 |
| 社区 | 居住在同一街道/社区范围内 | 验证 H5 LBS 匹配 |
| 意愿 | 问卷中"愿意尝试"评分 ≥ 7/10 | 筛选"说愿意"的人 |

#### 3.2 招募配额

| 分层 | 人数 | 说明 |
|---|---|---|
| 25-30 岁 男性 | 12 人 | 核心群体，验证男性参与意愿 |
| 25-30 岁 女性 | 8 人 | 对照组 |
| 31-40 岁 男性 | 10 人 | 核心群体，验证时间贫困者参与 |
| 31-40 岁 女性 | 8 人 | 对照组 |
| 其他（41+ 或自由职业） | 12 人 | 扩样，验证边界 |
| **合计** | **50 人** | 成本可控、统计有效 |

#### 3.3 招募渠道优先级

| 优先级 | 渠道 | 预期转化率 | 备注 |

### 6. 数据采集指标

#### 6.1 核心指标

| 指标 | 定义 | 采集方式 | 成功标准 |
|---|---|---|---|
| **活跃率** | 每周至少参与 1 次任务的用户占比 | 群内接龙/打卡 | ≥60% |
| **参与频次** | 人均每周完成任务数 | 群内记录 | ≥2 次/周 |
| **任务完成率** | 接受任务后实际完成比例 | 用户反馈 + 照片 | ≥70% |
| **留存率（7 日）** | Day 1 参与用户在 Day 7 仍活跃的比例 | 连续记录 | ≥50% |

#### 6.2 验证假设专用指标

| 假设 | 指标 | 采集方式 | 通过门槛 |
|---|---|---|---|
| **H3** | 非金钱激励发布后参与率提升幅度 | 对比 Day 5 前后参与率 | 激励发布后参与率提升 ≥15% |
| **H3** | 无心值兑换意愿（虚拟兑换） | 兑换型任务参与率 | ≥40% |
| **H5** | 距离 <1km 任务 vs >1km 任务接受率 | 对比两类任务接受率 | <1km 接受率比 >1km 高 ≥30% |
| **H5** | 配对型任务完成率 | 人工撮合后实际完成 | ≥50% |

#### 6.3 辅助指标

| 指标 | 用途 | 采集方式 |
|---|---|---|
| 任务晒图率 | 检验"荣誉感"驱动 | 群内照片/截图 |

#### 7.1 成功标准（全部达标 → 进入 Phase 1 MVP）

#### 7.2 止损标准（触发任一 → 暂停评估）
