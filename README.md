# 好事近 · 泛公益参与调研全案

> **把泛公益拆成 15 分钟、顺路、就近的轻量任务，用非金钱的"好心值 + 时间币"替代工资，让忙人也能把好事做成日常。**

---

## 项目简介

一个被现有志愿服务体系系统性忽略的细分人群——**"时间贫困 × 意愿充足 × 非金钱驱动 × 强地域性"**。志愿汇解决的是"组织如何管理志愿者"，腾讯公益解决的是"如何筹钱"，而"一个忙人如何在通勤和碎片时间里，顺手把好事做了"这件事，目前没有专属产品。

本项目包含完整的：

- **市场调研与需求验证**——大盘数据、人群画像、竞品分析
- **调研产品规划**——5 个核心假设 (H1–H5)、混合方法论、问卷/访谈提纲
- **产品 MVP 规划**——价值主张"好事近"、核心功能、非盈利正循环设计
- **叠加递进路径**——Phase 0 验证 → Phase 4 生态，每一层像搭乐高一样叠

### v2.0 线下活动融合方案（基于案例调研）

v2.0 将基于 [案例库](pages/cases.html) 中的真实社区公益实践，落地以下功能：

1. **议事会模式**（借鉴北京"共治坊"）— 投票结果生成需求清单，支持邻里议事
2. **友好商户体系**（借鉴"甜葡萄时间银行"/博爱超市）— 好心值兑换商户优惠
3. **技能认证标签**（借鉴杭州"义修哥"）— 搭档匹配增加技能资质
4. **公益众筹**（借鉴"甜葡萄时间银行"）— 好心值众筹+捐步换物
5. **适老改造场景**（借鉴"姥姥的药箱"/"李杜暖心圈"）— 场景匹配器新增上门服务
6. **时间银行**（借鉴南沙/"甜葡萄时间银行"）— 时间币存储制+三单联动

### 案例来源

案例库中的9个案例均来自2025-2026年公开报道的真实社区公益实践，来源包括：
