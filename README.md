# 好事近 · 泛公益参与调研全案

> **把泛公益拆成 15 分钟、顺路、就近的轻量任务，用非金钱的"好心值 + 时间币"替代工资，让忙人也能把好事做成日常。**

---

## 项目简介

一个被现有志愿服务体系系统性忽略的细分人群——**"时间贫困 × 意愿充足 × 非金钱驱动 × 强地域性"**。志愿汇解决的是"组织如何管理志愿者"，腾讯公益解决的是"如何筹钱"，而"一个忙人如何在通勤和碎片时间里，顺手把好事做了"这件事，目前没有专属产品。

本项目包含完整的：

- **市场调研与需求验证**——大盘数据、人群画像、竞品分析
- **调研产品规划**——5 个核心假设 (H1–H5)、混合方法论、问卷/访谈提纲
- **产品 MVP 规划**——价值主张"好事近"、核心功能、非盈利正循环设计
- **叠加递进路径**——Phase 0 验证 → Phase 4 生态，每一层像搭乐高一样叠

### v2.0 日常微好事生态（基于日常好事库）

v2.0 将基于 [日常好事库](pages/cases.html) 中的63个日常微好事模板，落地以下功能：

1. **议事会模式**（邻里投票决定下一件共同好事）— 投票结果生成需求清单
2. **友好商户体系**（好心值兑换商户优惠）— 激励日常善行
3. **技能认证标签**（搭档匹配增加技能资质）— 义修/义剪等技能互助
4. **公益众筹**（好心值众筹+捐步换物）— 集体完成一件好事
5. **适老改造场景**（场景匹配器新增上门服务）— 药箱整理/居家改造
6. **时间银行**（时间币存储制+三单联动）— 让日常好事可存储、可追溯

### 日常好事库说明

日常好事库中的63个模板均为日常小型社区微好事，覆盖6大类别：
- 邻里互助（9个）— 帮取快递、共享雨伞、帮提菜等
- 随手环保（8个）— 垃圾分类、摆正单车、清理小广告等
- 技能顺手（9个）— 教老人用手机、帮打印、修家电等
- 暖心陪伴（8个）— 陪老人聊天、给孩子读故事、帮遛狗等
- 节日小事（9个）— 包饺子分邻居、写春联、端午挂艾草等
- 闲置共享（10个）— 图书漂流、旧衣回收、共享工具箱等
