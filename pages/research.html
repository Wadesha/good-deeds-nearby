调研产品规划

需求假设与验证框架

所谓"调研产品"，不是写篇报告，而是把"验证需求"本身做成一个可复用、可量化、可迭代的方法包。下面这套方法包就是产品。

2.1 待验证的核心假设（Hypothesis List）

H1

时间贫困者仍有稳定参与意愿

▸ 验证方式：问卷 + 行为意向▸ 证伪：意愿分 < 中位、且无复购意向
H2

"就近 + 碎片"是参与第一驱动力

▸ 验证方式：联合分析 / 排序题▸ 证伪：排序中"时长认证/证书"高于"就近"
H3

非金钱激励（信用/好心值）足以驱动持续参与

▸ 验证方式：访谈 + A/B 模拟▸ 证伪：明确表示"没奖励就不做"且拒绝非货币权益
H4

男性 / 年轻人 / 职场人是供给侧缺口

▸ 验证方式：样本分布 + 动机差异▸ 证伪：该群体参与意愿与女性无显著差异
H5

地域性（社区 / LBS）是匹配关键

▸ 验证方式：LBS 任务模拟点击▸ 证伪：对"距离 < 1km"任务无偏好

2.2 方法论：混合方法（Mixed Methods）

原 则不要只发问卷。问卷给"量"，访谈给"为什么"，行为数据给"真做了没"。
定量（问卷，N≈600）  ──►  验证 H1/H2/H4/H5 的规模与分布
   │
深度访谈（N≈30）     ──►  验证 H3 动机，挖"为什么不做"的真障碍
   │
行为探针（小群 2 周） ──►  建微信群人工撮合"就近轻量好事"，看真实参与率
   │
竞品测绘（桌面）     ──►  已有，持续更新

2.3 调研工具一：问卷大纲（5 模块，约 25 题）

A

人口与"时间贫困度"

年龄 / 城市层级 / 职业 / 周工作小时；周均可自由支配的"整块时间"（>2h）？碎片时间场景（通勤/午休/排队/遛娃/运动）← 关键匹配锚点

B

公益参与现状

过去一年是否参与过泛公益？单次愿意投入时长：<15min / 15-30min / 0.5-1h / >1h ← 验证颗粒度

C

驱动力排序（联合分析核心）

6 项参与理由排序 ← 直接验证 H2

D

非金钱激励接受度（验证 H3）

好心值兑换偏好、时间银行存兑意愿。

E

障碍与流失

你不做公益的主因？如果有一款"顺路 15 分钟做好事"的小程序，参与意愿 1–10？

2.4 深度访谈提纲（8 主题，每场 45min）

  1. 上一次你"顺手帮了别人"是什么时候？什么触发了你？
  2. 你觉得自己"忙"吗？忙和"想做好事"之间怎么取舍？
  3. 你做过最持续的公益是什么？为什么能持续？为什么停了？
  4. 你对"志愿汇/腾讯公益"的体验？哪里别扭？
  5. 如果好事"就在楼下、只要 15 分钟"，你会做吗？
  6. 你怎么看"好心值/信用"这类非金钱回报？
  7. 时间银行（存时间取服务）你信吗？怕什么？
  8. 你愿意和"附近同频的人"一起做吗？社交是加分还是减分？

2.5 样本设计（分层配额）

维度分层目标占比
时间贫困度高（周整块时间 < 2h）/ 中 / 低高占比 ≥ 50%
年龄18-25 / 26-40 / 41-60 / 60+重点 26-40 职场人
地域一线 / 新一线 / 三线及以下一线 + 新一线 ≥ 60%
性别男 / 女刻意 oversample 男性（验证 H4 缺口）

2.6 成功标准（什么算"验证通过"）

  • H1 成立：核心人群（高时间贫困）中，参与意愿 ≥ 6/10 且 ≥ 40% 表示"有合适入口会持续做"。
  • H2 成立："就近 + 碎片"在驱动力排序中进入前 2。
  • 行为探针：2 周微信群撮合，人均真实参与 ≥ 1 次，且 ≥ 30% 主动问"下次什么时候"。
  • 可推进 MVP 的门槛：同时满足 H1 + H2，且非金钱激励在 H3 中不被明确拒绝。
