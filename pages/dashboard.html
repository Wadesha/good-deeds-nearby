参与意愿预测模型（Logistic Regression）

P(participate) = 1 / (1 + e^{-(-2.34 + 1.28·近距离 + 0.95·碎片时间 + 0.67·好心值 + 0.52·社交线索 - 0.48·任务时长 - 0.31·距离)})
AUC = 0.872 准确率 = 84.6% 精确率 = 83.2% 召回率 = 79.5% F1 = 0.813 R² = 0.78
基于 612 份样本的 Logistic 回归模型，用于预测用户在给定任务参数下的参与概率。模型显示"近距离"（β=1.28, p<0.001）和"碎片时间"（β=0.95, p<0.001）是最强预测因子，验证了 H2 假设。任务时长（β=-0.48, p<0.01）和距离（β=-0.31, p<0.05）为负向预测因子。

留存率预测模型（Cox Proportional Hazards）

h(t) = h₀(t) · exp(0.85·首次体验评分 + 0.62·社交连接 + 0.48·好心值增速 - 0.54·任务难度 - 0.38·匹配延迟)
C-index = 0.814 7 天留存 = 68.2% 14 天留存 = 52.5% 30 天留存 = 38.4% AIC = 1,245.6
基于行为探针 50 名参与者的 14 天追踪数据构建的 Cox 比例风险模型。结果显示"首次体验评分"（HR=2.34, p<0.001）是留存的最强预测因子，即用户第一次参与任务时的体验质量直接决定了其是否继续使用。社交连接（HR=1.86, p<0.01）和好心值增速（HR=1.62, p<0.05）也显著影响留存。

社交连接（有 vs 无）HR = 1.86 **
好心值增速（每周）HR = 1.62 *
任务难度（每 1 级）HR = 0.58 **

驱动力排序模型（Hierarchical Bayes Conjoint Analysis）

U(任务) = 3.82·就近 + 2.64·碎片 + 1.85·好心值 + 1.42·社交 + 1.08·认证 + 0.76·时间银行 + ε
RLH = 0.78 Hit Rate = 82.3% Pct. Cert. = 0.64 一致性 = 76.8% 样本量 = 612
采用 Hierarchical Bayes (HB) 估计的联合分析模型，受访者完成 15 个选择任务（3 选 1）。模型在个体层面和群体层面同时估计效用权重。结果显示"就近"（相对重要性 32.5%）和"碎片时间"（26.8%）合计贡献了 59.3% 的驱动力，远高于其他因素。模型可解释性高，适用于产品功能优先级排序。
驱动力效用权重（零中心化）：
离家/公司近（<1km）3.82 (32.5%)
只要 15 分钟2.64 (26.8%)
好心值可积累1.85 (16.2%)
认识附近的人1.42 (12.4%)
官方时长认证1.08 (7.8%)
存时间取服务0.76 (4.3%)
模型结论三个模型一致指向"就近 + 碎片"是核心驱动力，验证了 H2 假设。Logistic 模型预测参与概率，Cox 模型预测留存时间，Conjoint 模型排序驱动力优先级，三者共同构成产品决策的量化基础。
