产品路线图

叠加递进路径

核心思路：每一层都以上一层的"用户 + 数据 + 信任"为地基，能力像搭乐高一样往上叠，而不是一次性做重。

路线总览

阶段时间核心目标叠加的能力关键指标
Phase 0 验证0–3 月证伪 / 证实需求问卷 + 30 访 + 2 周行为探针H1–H5 通过门槛
Phase 1 MVP3–6 月跑通单点闭环小程序 + LBS 任务 + 好心值单社区周活、人均参与次数
Phase 2 正循环6–12 月非货币激励闭环时间币存兑 + 组织入驻 + 权益商城时间币流通率、复购率
Phase 3 网络效应12–24 月多城复制 + 智能匹配数据驱动推荐 + 跨社区 + 政府对接城市数、匹配成功率
Phase 4 生态24 月+泛公益基础设施开放 API + B 端 CSR 对接 + 影响力量化接入组织数、社会价值报告

递进的"杠杆点"

Phase 1 → 2 的杠杆

关键转折
时间币真的能兑到东西（否则激励失灵复发）。

Phase 2 → 3 的杠杆

规模放大
数据让匹配更准（否则信息失灵复发）。

Phase 3 → 4 的杠杆

成为基础设施
成为政府/企业的善意基础设施（否则持续失灵复发）。
逻 辑每一层都以上一层的"用户 + 数据 + 信任"为地基，能力像搭乐高一样往上叠，而不是一次性做重。
